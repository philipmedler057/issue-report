# Issue Report PWA

No Node.js required.

## Publish with GitHub Pages
1. Create a new GitHub repository, e.g. `issue-report`.
2. Upload all files from this folder to the repository root.
3. In GitHub go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**.
6. Save. GitHub will show the public URL after deployment.

## Install on iPhone
1. Open the GitHub Pages URL in Safari.
2. Tap Share.
3. Choose **Add to Home Screen**.

## Current features
- Projects
- Automatic issue numbering
- Photo from camera/gallery
- Description, location, category, status
- Local browser storage
- PDF export
- One issue per PDF page
- Offline shell via service worker

## Important
Data is stored only in the browser on the current device.
Clearing Safari website data can remove it.
For a later version, cloud sync/authentication should be added.
